ATENÇÃO: COMO O CÓDIGO É ESCRITO
  Quase todos os capítulos começam com "É vedado ao médico:". O texto de cada artigo abaixo
  disso descreve o que é PROIBIDO. Ex.: "Art. 39 Opor-se à realização de junta médica..."
  quer dizer que o médico NÃO pode se opor. A resposta precisa deixar isso claro.

COMO PREENCHER CADA PERGUNTA
  RESPOSTA:  a resposta certa, curta e completa (1 a 2 frases). Use as palavras do Código
             sempre que der. Se a pergunta tem mais de uma parte, responda todas.
  TRECHO:    copie e cole do PDF o trecho que prova a resposta, com o número do artigo
             (ex.: "Art. 39 Opor-se à realização de junta médica..."). OBRIGATÓRIO: é o que torna
             o gabarito verificável.
  PÁGINA:    número da página do PDF onde está o trecho.
  STATUS:    deixe OK. Troque por  DESCARTAR - <motivo>  se a pergunta estiver ambígua, errada,
             ou tiver mais de uma resposta possível. Não reescreva a pergunta, só marque.

REGRAS
  1. Responda só com o que está ESCRITO no Código. Nada de conhecimento próprio nem de outras
     resoluções do CFM.
  2. Cada campo numa linha só (um script vai ler este arquivo depois).
  3. Não altere as linhas [Pxx], TIPO: e PERGUNTA:, e não apague nenhum campo.
  4. Perguntas com TIPO "FORA DO DOCUMENTO" são de propósito sobre algo que acreditamos que o
     Código NÃO diz (servem pra testar se o RAG sabe dizer "não sei" quando deve). Procure no
     documento inteiro:
       - não achou  ->  RESPOSTA: NÃO CONSTA   |   TRECHO: -   |   PÁGINA: -
       - achou      ->  responda normalmente e escreva em STATUS:  OK - estava no documento
  5. "ONDE PROCURAR" é só uma dica pra agilizar, não a resposta.
